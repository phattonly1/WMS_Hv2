##### 📂 표준 운영점검일지 작성 기준

> [!INFO] 일지 작성 원칙
> 정규 순회 점검 시 아래 표준 조치 문구에 따라 작성하는 것이 기본이며, 추가적인 특이사항 발생 시에만 하단 비고란에 기재하십시오.

| 설비구분 | 측정항목 | 표준 조치 및 점검 내역 |
| --- | --- | --- |
| **일반항목** | 수소이온농도(pH) | 센서 세척 및 점검, 교정 실시, 표준물질 측정 (10.0 / 7.0) |
| **일반항목** | 용존산소(DO) | membrane 세척 및 점검, 필요시 교체, 포화도 교정, 표준물질 측정 |
| **일반항목** | 전기전도도(EC) | 전극 세척 및 점검, 표준용액 점검 (1,000 / 0 uS/cm) |
| **일반항목** | 수온 | 온도 센서 세척 및 기준온도계 대조 점검 |
| **일반항목** | 탁도(Turbidity) | 광학 렌즈 및 와이퍼 세척, 스팬 교정, 표준물질 측정 (126 NTU) |
| **분석기기** | 총유기탄소(TOC) | 반응조 세척, 시약 잔량 확인, 캐리어 가스압 확인, 장비 구동 상태 점검 |
| **분석기기** | 질산성질소(NO3) | 시약 흡입 노즐 세척, 검량선 확인, 광학 필터 점검 |
| **채수설비** | 수중펌프/배관 | 저류수조 세척, 채수밸브 점검, 펌프 토출 압력 및 채수 수위 확인 |
| **부대시설** | 통신/제어반 | 데이터 원격 전송 상태 확인, 전송장비(Datalogger) 이상 유무 확인 |
| **부대시설** | 항온항습/UPS | 실내 적정 온도(20~25℃) 유지 확인, 먼지필터 청소, 비상전원 상태 확인 |

##### 📂 주요 항목별 1차 자료선별 기준

| 항목 | 정상 분석 조건 | 이상치 판단 및 비정상 처리 기준 |
| --- | --- | --- |
| **pH** | `4.0 ~ 11.0` | 급격한 계단형 튐 발생 또는 센서 교정 전후 비정상 수치 제외 |
| **DO** | `1.0 ~ 20.0 mg/L` | 수온 대비 과포화(>20) 또는 펌프 정지 시 급락하는 무산소 수치 제외 |
| **EC** | 하천별 유동 판단 | 0에 수렴 시 채수 불능으로 판단 (폭우 시 희석 하락은 정상 반영) |
| **수온** | 기상청 기온 대조 | 수온이 외기온과 완전히 동기화되어 흔들릴 경우 센서 노출 의심 |
| **탁도 / TOC** | 최소 `0.1` 이상 | 수치가 0.0으로 고정되거나 마이너스 값 출력 시 기기 이상 처리 |
| **NH3-N** | 시약 반응 모니터 | 발색 불량으로 인한 0 값 또는 과도한 최대치 연속 시 제외 |

> [!TIP] 자료 선별 작업 Tip
> - 세팅 중 발생한 비정상 값은 반드시 **`[비정상]`**으로 분류 처리하십시오.
> - 현장 점검코드 미적용 데이터는 원인 및 일자 확인 후 **`[정상]`**으로 전환합니다.
> - **EC가 0에 가깝고 DO가 급감**하면 채수 펌프 정지 가능성이 매우 높으므로 채수 상태를 교차 확인하십시오.

##### 📂 일반항목 현장 점검 수칙 (방문 시)

> [!WARNING] 세척액 및 격막 취급 주의
> 일반항목 센서부는 킴테크, 면봉, 부드러운 솔을 사용하십시오. 증류수는 삼투압 현상으로 센서 격막을 손상시킬 수 있으므로 장시간 침적을 권장하지 않습니다.

- [x] **클로로필 렌즈**: 증류수로 부드럽게 세척하고, 킴테크로 강하게 문지르지 마십시오.
- [x] **클로로필 및 남조류 동시 0 측정 시**: 광학계 이상이므로 정밀 점검이 필요합니다.
- [x] **디스플레이 정지 버튼 주의**: 클로로필 센서 본체를 잡다가 디스플레이의 정지 버튼이 눌리지 않도록 주의하고 퇴실 시 값 변화를 확인하십시오.
- [x] **EXO 패널 단위 확인**: 조작 시 전기전도도(EC) 단위 변경 실수 여부를 퇴실 전 필히 재확인하십시오.

##### 📂 분석기기 점검 및 시약 관리 (주 1~2회)

> [!INFO] 가열 반응 장비 취급 요령
> 가열 반응 장비는 가열 사이클이 정상 종료되면 정지시키고, 미가열 상태인 경우 즉시 정지 후 세정 공정을 진행하십시오.

- [x] 누액 여부 및 시약 잔량을 확인하고, **강우 예보 전에는 비상출동 비교를 위해 미리 표준용액을 측정**해 둡니다.
- [x] **일부 시약 보충 시**: 표준용액 측정 실시 / **전체 시약 교체 시**: 교정(Calibration) 실시
- [x] 시약 교체 후에는 초기 펌핑을 통해 관로의 기포(에어)를 완전히 배출한 후 측정을 시작합니다.
- [x] **과황산칼륨**: 동결 및 결정 석출 방지를 위해 차가운 바닥에 직접 놓지 마십시오.
- [x] **냉장 보관 대상**: 표준용액, 아스코르빈산, 몰리브덴산은 반드시 냉장 보관하십시오.
- [x] **증류수 관리**: 주당 약 40L 소모되므로 오래된 약품과 증류수를 주기적으로 전량 폐기 후 신규 보충하십시오.
- [x] **밸브 점검**: 밸브를 수동 작동시켜 딸깍하는 작동 소음이 정상적인지 확인하십시오.

##### 📂 가스실 및 폐액 드레인 관리

1. **가스 봄베 점검 및 교체**
   - 장비별 규정 가스 압력을 확인하고, **잔여 압력이 200 psi 이하 도달 시 신규 봄베로 즉시 교체**하십시오.
   - **교체 요령**: 레귤레이터를 잠그고 봄베 밸브를 잠근 뒤 교체합니다. 교체 후 봄베 밸브를 개방할 때는 조금만 열지 말고 **끝까지 완전히 개방**하십시오.
   - **VOCs 가스 교체**: GC 장비 상태가 반드시 **`[Ready]`** 상태일 때만 교체하십시오 (`Not ready` 또는 `Running` 시 절대 금지). 수소 봄베는 약 3개월 정도 사용합니다.

> [!WARNING] 폐액 드레인 역류 주의
> 자연 낙차 압력으로 배수되는 드레인 라인은 튜브 끝단이 폐액에 잠기게 되면 공기 차단으로 배수가 멈추고 역류하므로 항상 튜브 끝을 액면 위에 띄워두십시오.

##### 📂 측정소 방문 보안 및 점검코드 변경

> [!WARNING] 보안 주의사항
> 측정소 입장 시 세콤(SECOM) 해제 여부와 채수시설 자물쇠 체결 상태를 반드시 확인하십시오.

- **복하천**: 세콤 해제 후 2~3초 후 다시 자동으로 잠기므로 즉시 문을 열어야 합니다.
- **흥천 창고 / 광주 창고 / 서상 입구**: `사내 보안 시트 / 담당자 문의 (보안코드 마스킹됨)`

- [x] 측정소 입장 즉시 전체 측정코드를 점검중(`B4`) 코드로 변경
- [x] 교정 또는 표준물질 측정 시 개별 항목을 정도관리(`E2`) 코드로 변경
- [x] 점검 완료 후 퇴실 시 정상 상태 코드로 원복 확인

> [!TIP] 원격명령 팁
> 현장에서 전체 코드 변경을 누락한 경우, 관제 시스템의 원격 명령 메뉴에서 `[전체 적용]`을 실행하면 일괄 변경할 수 있습니다.

##### 📂 수조 확인 및 필터 교체 (방문 시)

> [!INFO] 수위 이상 판단 기준
> - **저류수조 수위 저하**: 펌프 토출 압력 부족 또는 배관 이물질 유입 의심
> - **여과수조 수위 저하**: 여과 필터 막힘 의심

##### 하천수 공급 라인 흐름도

| 구분 | 경로 순서 | 사용 필터 규격 |
| --- | --- | --- |
| **저류수조 라인** | 수중펌프 → 채수배관(A/B) → 저류수조 → 드레인 | 밀폐형 / 개방형 |
| **여과수조 라인** | 수중펌프 → 채수배관(A/B) → 프리필터 → 여과필터(150메시) → 여과필터(100메시) → 여과수조 → 드레인 | 150 / 100 메시 |

1. **역세척 (월 1회 이상)**
   - 펌프실에서 펌프를 끈 상태로 들어올려 실시합니다 (역세척 후 저류수조 안정화 시간 필요).
2. **자동채수기 튜브 세척**
   - 자동채수기 흡입 튜브는 저류수조에 완전히 잠겨있을 때 세척해야 침적 이물질이 원활히 배출됩니다.
3. **프리필터 세척 (월 1회 이상)**
   - 세척 후 하천수를 받을 때 뚜껑의 공기(에어)를 반드시 빼주십시오.

##### 📂 채수실 점검 및 전선 결선 (월 1회 이상)

> [!DANGER] 수중펌프 과열 고장 주의
> 수중펌프는 본체의 80% 이상이 하천수에 잠겨있지 않으면 공랭 부족으로 모터가 과열되어 소손됩니다.

- **측정소별 특이사항**:
  - **달천**: 채수실 전원 트립 발생 시 현장 채수실로 직접 이동하여 복구
  - **여주**: 펌프 꺼짐 발생 시 측정소 판넬과 채수실 메인 차단기 양쪽 모두 확인
  - **인제**: 펌프 패널은 기본 `[수동]`, 조작 시 `[반자동]`, 최종 미세조정은 `[수동]`
  - **원주**: 수위 조절 시 판넬 하단의 잠금 핀을 먼저 인발한 후 조작
  - **인양 점검**: 펌프 인양 시 드럼롤, 케이블, 호이스트 와이어가 꼬이지 않고 잘 감기는지 확인

1. **차단기 차단 및 무전압 확인**
   - 작업 전 펌프실 분전반 메인 차단기를 반드시 내리고 무전압 상태를 확인합니다.
2. **호이스트 및 배관 분리**
   - 호이스트 와이어 및 펌프 토출 배관 체결부를 분리합니다.
3. **전선 절단 및 방수 결선 시공**
   - 펌프 전선 절단 후 색상을 일대일로 결선하고 `[1차 절연테이프(개별 1가닥)]` > `[2차 고무패드 방수(개별)]` > `[3차 절연테이프(전체 마감)]` 순으로 시공합니다.

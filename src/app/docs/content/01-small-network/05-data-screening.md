##### 📂 1차 자료 선별 요령

1. **선별 작업 경로 및 순서**
   - `시범사업` > `자료선별 확정` > `데이터 선별` 클릭 → 측정소 및 검색기간 설정 → 조회 → **신규차트 캡처(필수)** → 분석조건 설정 → 선별작업 진행

2. **항목별 분석조건 및 유효데이터 확정**
   - `pH`: `4.0 ~ 11.0` (교정값 초과 및 비정상 수치 제외)
   - `DO`: `1.0 ~ 20.0 mg/L` (비정상 수치 제외)
   - `EC / 수온 / NH3`: 별도 조건 미설정 (하천 상황에 따라 유동 판단)
   - `탁도 / TOC / NO3`: 최소 `0.1` / `0.05` (0값 제외)
   - 헌팅 등 비정상값은 **'비정상'**으로 수정하고, 코드 미변경 데이터는 원인 및 날짜 확인 후 **'정상'**으로 변경합니다.

> [!TIP] 신규차트 패턴 분석 Tip
> - **EC**: 0에 수렴하면 채수가 안 된 것이므로 전 항목 데이터 제외
> - **pH / 탁도**: 헌팅 시 안정화 기간 제외 (일시적으로 나타났다 사라지면 제외)
> - **DO**: 교정 후 구간 변경 확인, 일정값 지속 시 센서 이상 확인
> - **TOC / 질산성 / 암모니아성**: 0값 또는 최대값 홀딩 시 제외

##### 📂 월간보고서 작성 요령 (붙임 1 ~ 3)

- **자료 구성**:
  - **붙임1**: 현황 요약, 정도관리 현황, 비정상가동 내역 (조별 담당자 작성, 매월 초 조장에게 메일 발송)
  - **붙임2**: 측정소별 일간 가동률 (조별 담당자 작성)
  - **붙임3**: 차트 그래프 모음 (총괄 담당자 작성)
- **붙임2 엑셀 작성**: 선별 완료 후 유효데이터 조회에서 1일 데이터를 엑셀 출력하여 붙임2 파일에 붙여넣고 색 표현, 메모 작성, 총일수를 수정합니다 (**가동률 및 유효측정일수 수식 확인 필수**).

| 색 구분 | 구분명 | 상세 내용 및 가동률 영향 |
| --- | --- | --- |
| **흰색** | 정상데이터 | 유효측정일수 포함 |
| **노랑** | 유효데이터 제외 | 유효측정일수 제외 (**가동률 저하 발생**) |
| **파랑** | 운전정지 | 총일수 제외 (가동률 영향 없음) |
| **회색** | 정도검사 / 일반시험 | 총일수 제외 (가동률 영향 없음) |

- **사유 메모 작성 형식**: `[측정항목] 0/00~00, 측정불가(사유 : 00)으로 데이터 제외 다수`
  - *날짜 예시*: 일반 `11/1~20`, 운전정지 지속 중 `11/2~계속`, 연도 경과 시 `22/12/2~7/12`
  - *표준 사유 문구*: `"채수불가(사유: 수위 저하)로 운전정지"`, `"측정불가(사유: 강우로 인한 간헐 채수)로 데이터 제외 다수"`, `"0값 측정(사유: 기포 흡착)으로 데이터 제외 다수"`

측정/장애 이력 자동완성기 오프라인 지원

측정소, 측정항목, 발생일시, 종료일시를 붙여넣으면 [장비모델명]과 [지속기간]을 자동으로 완성합니다.

1. 엑셀 원본 붙여넣기 (Ctrl+V) 📌 원본 엑셀: E열 ~ I열 전체 복사
2. 처리 및 장비 기준 안내 최신 장비 DB 동기화

• 장비모델명 자동 매핑: 해당 측정소의 사이트 등록 장비 중 측정항목(TOC, TN, TP, 생물, VOCs 등)에 부합하는 장비 모델명을 자동으로 찾아 매핑합니다.

• 지속기간 자동 계산: 발생일시와 종료일시의 시/분 차이를 정밀 계산하여 'N일 N시 N분' 또는 'N시 N분' 형식으로 자동 산출합니다. (종료일시가 없거나 '-'이면 '-' 유지)

• 엑셀 호환: 완성된 결과는 [엑셀 복사] 버튼으로 복사한 뒤 엑셀에 바로 Ctrl+V 하시면 됩니다.
